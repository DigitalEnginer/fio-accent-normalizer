# Name Normalizer

Local MVP for normalizing one name component (given name, surname, or
patronymic) for speech synthesis.

## Status

Phase 1 is complete: the team will follow the Word instruction and place `+`
immediately before the stressed vowel.

Phase 2 is in progress: the local web interface lives in `web/`. No GPT API
call, database connection, or production integration has been implemented yet.

Read the MVP contract in `docs/01-mvp-contract.md`.
